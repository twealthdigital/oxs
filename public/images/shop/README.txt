Put the shop product images in this folder, using exactly these file names:

  desk-mini.png      (Desk Fan Mini)
  desk-pro.png       (Desk Fan Pro)
  stand-classic.png  (Stand Fan Classic)
  stand-max.png      (Stand Fan Max)
  tower-slim.png     (Tower Fan Slim)
  tower-quiet.png    (Tower Fan Quiet)

Tips: transparent background (PNG), square, about 800 x 800 px, the fan cut out and centred.
To use .webp or .jpg instead, change the extension in the matching <img src="/images/shop/..."> in index.html.
