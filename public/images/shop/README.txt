Put the shop product images in this folder, using exactly these file names:

  desk-mini.webp      (Desk Fan Mini)
  desk-pro.webp       (Desk Fan Pro)
  stand-classic.webp  (Stand Fan Classic)
  stand-max.webp      (Stand Fan Max)
  tower-slim.webp     (Tower Fan Slim)
  tower-quiet.webp    (Tower Fan Quiet)

Tips: transparent background (WebP), square, about 640 px wide, the fan cut out and centred.
To use .webp or .jpg instead, change the extension in the matching <img src="/images/shop/..."> in index.html.
